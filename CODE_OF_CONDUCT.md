# Code of conduct

Iris uses the Contributor Covenant, version 2.1, as its code of conduct:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

The code of conduct applies to all project spaces: the repository, issues, pull
requests, discussions and reviews. It applies to people and to the agents that
people run.

## Report a problem

1. Write to the maintainer, GitHub user `divyekant`, with the contact on the
   GitHub profile of that user.
2. Say what happened, where, and when. Add links if you have them.

The maintainer reads each report in private and answers within 7 days. The
maintainer does not tell other people who made the report.

## Enforcement

The maintainer uses the enforcement guidelines of the Contributor Covenant 2.1:
correction, warning, temporary ban, and permanent ban.
