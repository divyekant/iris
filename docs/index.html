Iris

Iris is a local email tool for people and their agents. It is open source (Apache-2.0). Each person runs an own copy of Iris on an own computer or server.

Iris reads Gmail with the Gmail API. Release 1 asks Google only for read access (gmail.readonly). Iris keeps its copy of the mail on the machine of the person. If the person selects a hosted model, Iris sends mail data to that model provider, and the provider can keep it. See the privacy policy.

Google sign-in

Iris has no shared Google app. Each person makes an own Google OAuth client and gives its file to the own Iris install. Google then shows the name of the app that the person made. The person is the developer of that app.

For builders

The data of Iris is an open model: a set of JSON documents with JSON Schema files and a conformance kit. A program outside Iris can write and read these documents. Read the builder guide.
