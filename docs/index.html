Iris

Iris is a local email tool for people and their agents. It is open source (Apache-2.0). Each person runs an own copy of Iris on an own computer or server.

Iris reads Gmail with the Gmail API. Release 1 asks Google only for read access (gmail.readonly). Iris keeps a copy of the mail on the machine of the person, and nowhere else.

Google sign-in

Iris has no shared Google app. Each person makes an own Google OAuth client and gives its file to the own Iris install. Google then shows the name of the app that the person made. The person is the developer of that app.
