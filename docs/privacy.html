Iris privacy policy

Date: 2026-11-15

Iris is a program that each person runs on an own computer or server. This policy has two parts: the Iris install of the person, and the Iris project.

1. The Iris install of the person

  • Iris reads the Gmail mailbox of the person with the Gmail API, with the scope gmail.readonly. Iris does not change, send or delete mail.
  • Iris stores a local copy of each message, including the raw mail, in the data folder on the machine of the person. This data stays on that machine, under the control of the person.
  • Iris encrypts the Google refresh token before it writes the token to disk. Iris keeps the access token in memory only.
  • If the person turns on a hosted model, Iris sends the text of a message to the model provider that the person selects, with the key of the person. The terms of that provider apply to that text. A local model sends no data off the machine.
  • To delete all data, the person deletes the Iris data folder. To remove the access of Iris, the person removes the app at myaccount.google.com/connections.

2. The Iris project

  • The Iris project receives no mail data, no tokens and no usage data from an install. Iris has no usage data collection.
  • The Iris project has no server that an install connects to.
  • These pages set no cookies and contain no analytics. The pages are hosted on GitHub Pages. GitHub can record the requests to these pages, as its own privacy statement says.

Google API Services User Data Policy

The use of information received from Google APIs by Iris follows the Google API Services User Data Policy, including the Limited Use requirements.

Changes and contact

Changes to this policy are in the history of the Iris repository. For a question, open an issue there.
