Iris privacy policy

Date: 2026-11-15

Iris is a program that each person runs on an own computer or server. This policy has two parts: the Iris install of the person, and the Iris project.

This policy applies to Iris release 1. A later release that can change, send or delete mail updates this policy in the same release.

1. The Iris install of the person

  • Iris reads the Gmail mailbox of the person with the Gmail API, with the scope gmail.readonly. Iris release 1 does not change, send or delete mail.
  • Iris stores a local copy of each message, including the raw mail, in the data folder on the machine of the person. Iris does not send this copy anywhere. Only the model step below sends mail data off the machine, and only when the person selects a model that runs on another machine.
  • Iris encrypts the Google refresh token before it writes the token to disk. Iris keeps the access token in memory only.
  • If the person turns on a hosted model, Iris sends mail data to the model provider that the person selects, with the key of the person. A model request can contain the text of a message, the headers that the model needs, the sender and the other parties of the message, and the context of its thread. The terms of that provider apply to this data, and the provider can keep it. If the person uses a model server, Iris sends the same data to the address of that server. The data stays on the machine only when the server runs on the same machine.
  • To delete the data of the Iris install, the person deletes the Iris data folder. Each copy that Iris made outside the data folder is separate: a backup of iris backup (with the mail and the key) and an output of iris export (with the mail). Delete each of these copies too. For data that Iris sent to a hosted model, see the terms of that provider.
  • To remove the access of Iris, the person removes the app at myaccount.google.com/connections.

2. The Iris project

  • The Iris project receives no mail data, no tokens and no usage data from an install. Iris has no usage data collection.
  • The Iris project has no server that an install connects to.
  • These pages set no cookies and contain no analytics. The pages are hosted on GitHub Pages. GitHub can record the requests to these pages, as its own privacy statement says.

Google API Services User Data Policy

The use of information received from Google APIs by Iris follows the Google API Services User Data Policy, including the Limited Use requirements.

Changes and contact

Changes to this policy are in the history of the Iris repository. For a question, open an issue there.
